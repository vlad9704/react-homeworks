# Lesson 01 — Render и commit на счётчике

## Цель

Различить вычисление компонента и изменение DOM.

## Что нужно сделать

- Создайте родителя со счётчиком и дочерний компонент с постоянным текстом. Добавьте кнопку изменения счётчика.
- Добавьте диагностический лог в тело ребёнка и MutationObserver для его DOM-узла с обязательной очисткой подписки.
- Сравните обновление родителя и изменение отдельного prop title ребёнка. Опишите, какие наблюдения относятся к render,
  а какие — к DOM.

## How to run

npm install
npm run dev
